# W0010 - Unused Function Argument

This diagnostic has been retired and is no longer reported.

The Erlang compiler already reports unused function arguments as `L1268`
(`variable 'X' is unused`), and ELP offers a quick-fix for it that prefixes the
variable with an underscore.

An argument that every clause of a function ignores, and that could therefore
be removed, is reported by [W0088](W0088.md).

Configuration entries and suppressions naming `W0010` are still accepted, but
have no effect and can be removed.
