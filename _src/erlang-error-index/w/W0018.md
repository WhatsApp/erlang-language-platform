# W0018 - Unexpected semicolon or dot

This diagnostic has been retired and is no longer reported.

The Erlang compiler already reports a misplaced `;` or `.` between function
clauses as a syntax error, and ELP reports mismatched clause heads as `P1700`.

Configuration entries and suppressions naming `W0018` are still accepted, but
have no effect and can be removed.
